# gasto-publico-brasil

## Uso de IA

Este projeto foi desenvolvido por mim, com apoio de ferramentas de IA:

- **Modelo:** Claude Opus 5.5 (`claude-opus-5-5`), da Anthropic
- **Agente:** Claude Code, no aplicativo desktop do Claude (aba Code)

Usei a IA para pesquisar fontes de dados e para configurar o ambiente e o repositório. A pasta `testes_ia/` contém testes escritos pela IA para validar fontes e métodos (gráfico de saúde e dashboard de gasto social); ela não faz parte da minha análise. Um relatório detalhado de uso será adicionado em breve.
